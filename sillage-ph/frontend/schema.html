Sillage PH database schema

Users, account roles, perfumes, and favorites are stored separately. The relationships below show how they connect.

Users & account roles

The users table is auth.users, managed by Supabase Authentication. It is in the auth schema, separate from the application tables in public. View accounts in Supabase under Authentication → Users.

Account roles

user_id Primary and foreign key · uuid

role text

If no role record exists, the app treats the account as a user. An assigned admin role grants catalog management.

Favorites & perfumes

Users and perfumes have a many-to-many relationship through favorites. Each user can save a particular perfume only once.
