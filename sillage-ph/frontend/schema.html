Sillage PH database schema

Users, account roles, perfumes, and favorites are stored separately. The relationships below show how they connect.

This diagram includes the separate Users table prepared in sql/users.sql. Apply that migration in Supabase before using this diagram as evidence of the live database.

Users & account roles

public.users is the application's separate users table. Each ID references auth.users.id; Supabase Authentication handles sign-in. Email addresses are synchronized from Auth and are not accessible through the public API.

Account roles

If no role record exists, the app treats the account as a user. An assigned admin role grants catalog management.

Favorites & perfumes

Favorites connect an account role record to a perfume. Each account can save a particular perfume only once.
